# راه‌اندازی رایگان دستیار هوشمند شوشترجوان

این راهنما برای راه‌اندازی بک‌اند هوش مصنوعی پروژه با گوشی اندرویدی نوشته شده است. کد Worker و اتصال دانشنامه در مخزن آماده است؛ فقط حساب رایگان Cloudflare و دو مقدار محرمانه برای استقرار لازم است.

## هزینه

- برای شروع از Cloudflare Workers Free و سهمیه رایگان Workers AI استفاده می‌شود.
- سهمیه رایگان فعلی Workers AI برابر ۱۰٬۰۰۰ Neurons در روز است؛ پس مصرف نامحدود نیست و بعد از اتمام سهمیه روزانه، درخواست‌ها تا زمان بازنشانی سهمیه ممکن است پاسخ نگیرند.
- برای این راه‌اندازی نباید طرح پولی یا روش پرداخت فعال کنی. اگر داشبورد درخواست ارتقا یا افزودن روش پرداخت کرد، ادامه نده.

## مرحله اول: ساخت حساب Cloudflare

1. با مرورگر گوشی وارد https://dash.cloudflare.com/sign-up شو و حساب رایگان بساز.
2. ایمیل را تأیید کن و وارد داشبورد شو.
3. از صفحه اصلی حساب، مقدار **Account ID** را پیدا و کپی کن.

## مرحله دوم: ساخت API Token برای استقرار

1. در Cloudflare به **My Profile → API Tokens → Create Token** برو.
2. قالب **Edit Cloudflare Workers** را انتخاب کن.
3. اگر صفحه اجازه تنظیم جزئیات می‌دهد، دسترسی را فقط برای همان حساب و مجوزهای لازم استقرار Worker محدود کن.
4. توکن را بساز و همان لحظه کپی کن؛ این مقدار محرمانه است. آن را در چت، فایل عمومی یا کد سایت نفرست.

## مرحله سوم: ثبت دو Secret در GitHub

1. در گوشی وارد مخزن https://github.com/salhyrfan575-sketch/Dua_app شو.
2. به **Settings → Secrets and variables → Actions** برو.
3. روی **New repository secret** بزن و این دو مقدار را جداگانه ثبت کن:
   - نام: `CLOUDFLARE_API_TOKEN` — مقدار: توکن مرحله قبل
   - نام: `CLOUDFLARE_ACCOUNT_ID` — مقدار: Account ID مرحله اول
4. مقادیر را در فایل‌های سایت یا پیام عمومی قرار نده.

## مرحله چهارم: استقرار Worker

1. در مخزن به **Actions** برو.
2. از فهرست سمت چپ **Deploy ShoushtarJavan AI Worker** را انتخاب کن.
3. روی **Run workflow → Run workflow** بزن.
4. پس از موفقیت، خروجی اجرا را باز کن. Wrangler نشانی Worker را نشان می‌دهد؛ معمولاً شبیه این است:
   `https://shoushtarjavan-ai.<نام-حساب>.workers.dev`
5. نشانی دقیق را برای مدیر پروژه بفرست تا به سایت متصل شود.

## مرحله پنجم: بررسی

پس از اتصال نشانی، این مسیر باید وضعیت سرویس را نشان دهد:

`https://نشانی-worker/health`

پاسخ موفق شامل `"status":"ok"` است. سپس دستیار سایت را با چند سؤال عمومی و چند سؤال درباره شوشتر آزمایش می‌کنیم.

## نکات امنیت و محدودیت

- کلید API در مرورگر کاربران قرار نمی‌گیرد؛ احراز هویت Cloudflare فقط در GitHub Secrets استفاده می‌شود.
- Worker درخواست‌های مرورگر را به دامنه سایت محدود می‌کند و برای هر IP یک محدودیت اولیه ۸ درخواست در دقیقه دارد. این محدودیت حافظه‌ای و best-effort است، نه سامانه ضدسوءاستفاده کامل.
- این نسخه مدل زبانی عمومی را اجرا می‌کند و دانشنامه شوشتر را هنگام پاسخ به‌عنوان منبع زمینه‌ای به آن می‌دهد؛ مدل از صفر آموزش داده نشده است.
- جست‌وجوی زنده اینترنتی هنوز در این نسخه فعال نیست. برای اطلاعات لحظه‌ای نباید ادعای جست‌وجوی وب کند.
- هیچ مدل هوش مصنوعی تضمین نمی‌کند همه سؤال‌ها را بداند؛ پاسخ‌ها باید آزمایش و در موضوعات حساس با منبع بررسی شوند.
