# وب‌سایت شوشترجوان

وب‌سایت خبری و فرهنگی شوشترجوان با HTML/CSS/JavaScript، راست‌چین و واکنش‌گرا.

## امکانات
- بنر ۱۶:۹ با اسلایدشو خودکار تصاویر آثار تاریخی شوشتر
- بخش آخرین اخبار، تولیدات اختصاصی و پرونده آثار تاریخی
- معرفی آثار با توضیحات بازشونده
- جایگاه لینک اینستاگرام، ایتا و آپارات
- دکمه بازگشت به بالای صفحه

## ویرایش
محتوا و ساختار در فایل index.html قرار دارد. کارت‌های خبری و تولیدات را می‌توان در بخش‌های news و exclusive تکثیر و ویرایش کرد. لینک شبکه‌ها در انتهای فایل و در بخش social با تغییر مقدار href تنظیم می‌شود.

## انتشار و دامنه
فایل workflow انتشار خودکار GitHub Pages در .github/workflows/pages.yml قرار دارد. فایل CNAME دامنه Shoushtarjavan.ir را مشخص می‌کند. برای فعال شدن سایت باید در تنظیمات مخزن، Pages با منبع GitHub Actions فعال شود و DNS دامنه به GitHub Pages متصل شود. تنظیم DNS از داخل مخزن انجام نمی‌شود.

## یادداشت محتوا و تصاویر
متن‌های بخش خبر و برخی کارت‌ها نمونه نمایشی‌اند و خبر روز محسوب نمی‌شوند. تصاویر از Wikimedia Commons فراخوانی می‌شوند؛ پیش از انتشار عمومی، مجوز هر تصویر و الزام انتساب عکاس بررسی شود.
